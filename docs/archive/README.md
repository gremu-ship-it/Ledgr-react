fixes they produced. They are kept for traceability (each was written on the
branch/date noted inside it) but do **not** describe the current state of the
codebase — verify against the code before acting on anything in them.

`DEPLOYMENT.md`, `PAYCHANGU_SETUP.md`, `BRANDING_SETUP.md`,
