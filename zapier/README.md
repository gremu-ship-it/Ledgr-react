# Ledgr Zapier App

This is the Zapier Platform CLI scaffold for Ledgr's public API.

Implemented triggers:

- New Invoice
- New Expense
- Invoice Paid

Implemented actions:

- Create Invoice
- Record Expense

## Local validation

```bash
cd zapier
npm install
npx zapier validate
```

## Submission

Submission to Zapier's Developer Platform requires a Zapier developer account and manual review from the Zapier dashboard. Use this directory as the app source when creating/submitting the Ledgr Zapier app.
